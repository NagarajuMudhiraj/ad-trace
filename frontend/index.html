About AD-TRACE

AD-TRACE (Alzheimer's Protein Association Analysis) is a scientific intelligence dashboard designed for computational biology research, target prioritization, and zero-leakage sequence evaluation.

Research Milestone: AD-TRACE incorporates a breakthrough SOTA (State of the Art) multi-modal architecture achieving 93.44% Validation Accuracy and 0.9468 ROC-AUC by uniting ProtT5 protein language models, STRING interactome hub proximity, and cDNA codon bias.

Built for academic rigor, AD-TRACE seamlessly integrates live statistical ML inference with authentic multi-database biological evidence: GTEx v10 brain transcriptomics, STRING v12 physical interactomes, and AlphaFold 3D coordinates.

Version 1.0.0 • Non-Clinical RUO

AD-TRACE Quick Help Guide

  1. Enter a sequence: Paste your FASTA-formatted or raw amino acid protein sequence into the input area.
  2. Click "Analyze Sequence": The server validates against the standard 20 amino acid alphabet, computes genuine biophysical descriptors, evaluates the association classifier, and performs identity mapping against 1,416 benchmark proteins.
  3. Explore the Biological Evidence Tabs:
    • Brain Expression: 13 GTEx v10 human brain regions (baseline non-diseased TPM).
    • Interaction Network: STRING v12 physical/functional interactome with interactive zoom/pan.
    • 3D Structure: AlphaFold 3Dmol.js viewer with pLDDT confidence spectrum.
  4. Understanding "SOTA": SOTA stands for State-of-the-Art (93.44% Accuracy, ROC-AUC 0.947), representing the peak multi-modal research benchmark.
  5. Export Results: Download comprehensive reports in CSV or JSON format from the Detailed Report tab.
